# Пресеты маршрутизации AmneziaGeo

Готовые списки приложений для Android, Windows и Linux. Их можно вставить в пресет панели AmneziaGeo и раздать клиентам
через шаблон. Выберите список исключений из VPN или список приложений, для которых нужен VPN.

## Файлы

| Платформа | Поле в панели | Правил | Текст для вставки                    | Каталог приложений                     |
|-----------|---------------|-------:|--------------------------------------|----------------------------------------|
| Android   | Напрямую      |    827 | [TXT](russian-apps-android-apps.txt) | [JSON](russian-apps-android-apps.json) |
| Android   | Через VPN     |    162 | [TXT](unbanru-android-apps.txt)      | [JSON](unbanru-android-apps.json)      |
| Windows   | Напрямую      |     40 | [TXT](russian-apps-windows.txt)      | [JSON](russian-apps-windows.json)      |
| Windows   | Через VPN     |    135 | [TXT](unbanru-apps-windows.txt)      | [JSON](unbanru-apps-windows.json)      |
| Linux     | Напрямую      |     14 | [TXT](russian-apps-linux.txt)        | [JSON](russian-apps-linux.json)        |
| Linux     | Через VPN     |     84 | [TXT](unbanru-apps-linux.txt)        | [JSON](unbanru-apps-linux.json)        |

Числа в таблице обозначают количество правил. У одного приложения может быть несколько исполняемых файлов или вариантов
имени.

## Создание пресета

1. В панели AmneziaGeo откройте **Клиенты → Пресеты маршрутизации → Добавить**.
2. Дайте пресету имя, например **«Android — российские приложения напрямую»**.
3. Откройте нужный TXT, скопируйте весь текст в поле из таблицы и нажмите **Enter**, чтобы добавить правила.
4. Выберите режим маршрутизации.
    - **VPN для всего, кроме списка исключений.** Вставьте список в **«Напрямую»** и включите **«Всё через VPN»**.
    - **VPN только для выбранных приложений.** Вставьте список в **«Через VPN»** и оставьте **«Всё через VPN»**
      выключенным.
5. В разделе **«Шаблоны»** выберите клиентские шаблоны, которым нужно раздавать этот пресет, и нажмите **«Сохранить»**.

Для этих сценариев оставьте **«Весь UDP через туннель»** выключенным. Эта опция отправляет в туннель UDP-трафик
независимо от списков.

## Получение пресета на клиенте

Приложение AmneziaGeo получает пресеты при обмене с сервером для конфигурации, использующей выбранный шаблон. Полученный
пресет появляется в списках маршрутизации клиента.

- **«Включён по умолчанию»** активирует пресет при первом получении, если у клиента ещё нет активного списка
  маршрутизации.
- **«Только чтение»** применяет обновления пресета автоматически. Пользователь по-прежнему может включать и выключать
  список. Для редактируемого пресета клиент предлагает принять новую версию.

Если сервер отклоняет Android-список из 827 правил из-за лимита, нужна версия панели с поддержкой **1024 правил в одном
пресете**.

## Формат файлов

TXT содержит правила через запятую. Поле панели, в которое вставлен текст, определяет направление трафика.

| Платформа | Пример правила          | Как клиент находит приложение                 |
|-----------|-------------------------|-----------------------------------------------|
| Android   | `app:pkg=ru.rutube.app` | По идентификатору установленного пакета       |
| Windows   | `app:name=Discord.exe`  | По имени исполняемого файла, включая `.exe`   |
| Linux     | `app:name=discord`      | По имени исполняемого файла с учётом регистра |

JSON содержит каталог тех же записей. На Android в нём есть `name`, `packageId` и `storeUrl`. Для Windows и Linux
используются `name`, `executable`, `rule` и `sourceUrl`. Значение `null` означает, что название или карточку
Android-приложения не удалось подтвердить по точному идентификатору пакета. Такие записи сохраняются в списке правил.
